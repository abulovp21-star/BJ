## 🔴 КРИТИЧНО — сделай это первым, независимо от остального
В `bj.py`, `run.py` и `webapp_server.py` был захардкожен настоящий токен бота как
fallback-значение (`os.getenv("BOT_TOKEN", "8161712628:AAHd...")`). Если этот код
хоть раз попадал в репозиторий (даже приватный) — токен нужно считать
скомпрометированным.

**Сделай сейчас:**
1. @BotFather → `/mybots` → бот → **API Token → Revoke current token**
2. Новый токен → Railway → Variables → `BOT_TOKEN`

Хардкод убран из кода — теперь при отсутствии переменной окружения `BOT_TOKEN`
приложение просто не запустится (`os.environ["BOT_TOKEN"]`), вместо того чтобы
тихо использовать старый слитый токен.

## 🐛 Найденные и исправленные баги

- **Дилер "тупил"**: константа `DEALER_WEAKNESS = 0.10` заставляла дилера в 10%
  случаев останавливаться ниже 17 вопреки правилам. Убрано полностью (в `bj.py`
  и `webapp_server.py`).
- **Утечка языка в группах**: множество команд (`/profile`, `/cards`, `/upgrade`,
  `/bonus`, `/shop`, `/ref`, `/settings` и ~20 админ-команд) показывали язык из
  личных настроек пользователя, а не язык группы. Теперь везде используется
  `eff_lang(cid, uid)` — в группе все видят один язык, который выставил админ.
- **`/upgrade` обещал несуществующий бонус**: текст всё ещё говорил "+1% к шансу
  за уровень" после того, как механика брасков стала детерминированной
  (уровень выше → 100% победа). Текст и мёртвые константы `TOSS_*_CHANCE` убраны.
- **Требования (`requirements.txt`) и `Procfile` в этой выгрузке относятся
  только к веб-приложению** (`aiohttp`+`asyncpg`, `web: python webapp_server.py`)
  — в них нет `aiogram`, которая нужна для `bj.py`. Похоже, у бота есть свой
  отдельный Procfile/requirements на Railway, который просто не был приложен
  к этой выгрузке. Я не стал их менять, чтобы не сломать существующую
  архитектуру — просто проверь, что у сервиса с ботом отдельно есть свой
  `aiogram` в зависимостях.

## 💰 Экономика

- **Два раздела магазина**: (1) тг-звёзды ⭐ → звёзды бота 💫 (50→50, 100→110,
  250→280, 500→550, 1000→1200), (2) звёзды бота 💫 → VIP/фишки.
- **VIP**: убраны тарифы на 30/90 дней, остался один — **навсегда за 119💫**.
- **Реферал**: теперь начисляет звёзды бота (3💫 обычным, 5💫 VIP-рефереру)
  вместо фишек.
- **`/reftop <дни>`** — новая команда только для создателя, топ по количеству
  рефералов за N дней.
- **`/givestars` / `/takestars`** — админские команды выдачи/списания звёзд
  бота (по аналогии с `/givec` / `/takec` для фишек).
- Профиль (`/profile`) теперь показывает баланс звёзд бота.

## 🎲 Игровые механики

- **Карточный бросок (`/cards`)**: полностью детерминирован по уровню —
  выше уровень соперника = 100% победа, ниже = 100% поражение, равный =
  монетка. Проигравший не получает ничего (награда только при победе
  челленджера).
- **Дилер**: играет строго по правилам, плюс добирает на мягких 17
  (soft 17 — стандарт большинства казино).
- **Страховка**: если у дилера туз — можно застраховать половину ставки
  (`/insure` / `/noinsure` в боте, кнопки в мини-аппе), выплата 2:1 при
  блэкджеке дилера.
- **Лимиты ставок**: минимум 100, максимум 1 000 000 (было — только минимум).

## 📖 Прочее в боте

- Кнопка **"❓ Как играть?"** в настройках — подробное объяснение правил
  человеческим языком, отдельно от списка команд `/help`.
- Пользовательское соглашение теперь **сворачиваемое**
  (`<blockquote expandable>`) вместо простого blockquote.

## 🎮 Мини-апп — полностью переписан

**Новое:**
- Меню: Играть / Магазин / Лидерборд / Настройки (как просил, "как в самом боте")
- Магазин: 4 платных скина карт (Neon Nights, Royal Velvet, Gold Foil, Holo
  Shift) + Classic бесплатный; 4 платных рамки профиля (Bronze, Silver, Gold,
  Diamond) + None бесплатная. Всё покупается за 💫 звёзды бота.
- Лидерборд (по балансу / по победам), настройки (звук вкл/выкл, язык,
  "как играть")
- Аватарки игроков — реальное фото из Telegram через Bot API
  (`/avatar/{uid}`), с фоллбэком на цветной кружок с инициалом, если у
  пользователя приватность фото закрыта
- Живые анимации раздачи карт, подсветка активного игрока, всплывающие
  бейджи результатов
- Быстрые комментарии/эмодзи над столом (😂🔥😱👏💀🍀 + свой текст)
- Звук — синтезированные тона через Web Audio API (не файлы — не требует
  интернета и не может нарушить чьи-то авторские права)
- Подбор игроков: минута ожидания, старт даже с 1 игроком по истечении
  времени; при 3+ игроках можно проголосовать "начать сейчас"
- Страховка, лимиты ставок 100–1 000 000 — как в боте

**Важные технические примечания:**
- Скины и рамки нарисованы CSS/градиентами, а не картинками — так у тебя
  нет юридического риска по чужим изображениям, апп быстро грузится, и это
  легко доработать позже.
- "Как играть" в мини-аппе — это понятный экран-гайд с разделами (цель,
  карты, ход раунда, страховка и т.д.), а не полноценный интерактивный
  тренажёр со скриптованной раздачей. Полноценный тренажёр — отдельная
  большая задача, скажи, если нужен именно он.
- Экономика мини-аппа (выплаты 3:2 за блэкджек, 1:1 обычная победа, пуш,
  страховка 2:1) продублирована в `webapp_server.py` и **сверена вручную**
  на совпадение с `bj.py` — числа идентичны.
